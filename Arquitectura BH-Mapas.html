Arquitectura BH-Mapas

Rastreo vehicular en tiempo real: una app híbrida transmite la posición GPS y un hub de SignalR la retransmite a todos los navegadores conectados.

mensaje SignalR en tiempo real (WebSocket)
llamada interna / JS interop
referencia de proyecto (DTO compartido en compilación)
net10.0-android / ios / maccatalyst / windows

BH-Mapas.Client

  • .NET MAUI + Blazor Hybrid (UseMaui, BlazorWebView)
  • Gps.razor lee el GPS nativo con Geolocation.Default.GetLocationAsync cada 3s
  • Envía cada posición al hub con HubConnection.SendAsync
  • Pinta su propia posición en un mapa Leaflet embebido vía interop JS
net10.0 · Sdk.BlazorWebAssembly

BH-Mapas.Web

  • Blazor WebAssembly puro, corre en el navegador del operador
  • MonitoreoVehiculo.razor se suscribe a RecibirUbicacionVehiculo
  • Actualiza el mapa Leaflet con cada posición recibida en vivo
net10.0 · Sdk.Web

BH-Mapas.API

  • UbicacionHub (SignalR) expuesto en /hubs/ubicacion
  • Retransmite con Clients.Others.SendAsync: todo lo que entra, sale a los demás
  • CORS abierto con credenciales (requerido por SignalR)
  • Controllers REST + OpenAPI como capa aparte, sin relación con el hub
net10.0 · class library

BH-Mapas-Shared

  • Único punto de verdad del contrato: record UbicacionVehiculoDto
  • Referenciada por ProjectReference desde Client, Web y API
  • Evita serializar/deserializar a mano entre las tres apps

Detalle de red: en el emulador Android, 10.0.2.2 apunta al host (la PC), por eso Gps.razor usa esa IP en vez de localhost cuando compila para #if ANDROID; el resto de las plataformas usa localhost:5101 directamente.
